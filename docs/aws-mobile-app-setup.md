# AWS Console Mobile App (Android) Sign-In Reference

This guide provides the exact fields and values needed to sign in to the **AWS
Console Android App** using IAM user `df`.

---

## Sign-In Fields & Values

When opening the AWS Console mobile app on Android, select **Sign in with AWS**
&rarr; **IAM user**:

| Field Name in Android App          | Value to Enter                          | Notes                                                    |
| :--------------------------------- | :-------------------------------------- | :------------------------------------------------------- |
| **Account ID or account alias**    | `275517639819`                          | Your 12-digit AWS Account ID                             |
| **IAM user name**                  | `df`                                    | The IAM username created in IAM                          |
| **Password**                       | _(Your console password for `df`)_      | The password assigned when creating `df` in IAM          |
| **MFA code** (Prompted next)       | _(6-digit code from authenticator app)_ | Generated by device `arn:aws:iam::275517639819:mfa/Zeus` |
| **Default Region** _(if prompted)_ | `Europe (Frankfurt)` (`eu-central-1`)   | The region where your EC2 instance is hosted             |
| **Account Nickname** _(optional)_  | `df-aws-frankfurt`                      | Local label inside the Android app                       |

---

## Troubleshooting Mobile App Sign-In

1. **"Account ID or alias is invalid"**:
    - Ensure you type the 12 digits without hyphens or spaces: `275517639819`.
2. **"MFA code is required"**:
    - User `df` has Multi-Factor Authentication enabled (`Zeus`). Open your
      authenticator app (Google Authenticator, Microsoft Authenticator, etc.)
      and enter the active 6-digit code.
3. **Did not set a Console Password for `df`?**:
    - If user `df` only has programmatic access keys and no console password,
      log into the web console as Root &rarr; go to **IAM** &rarr; **Users**
      &rarr; **df** &rarr; **Security credentials** &rarr; **Console access**
      &rarr; click **Enable console access** and set a password.
